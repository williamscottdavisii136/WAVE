# Phase 2C R&D Credibility, Legitimacy, and Evidence Methodology Addendum

Date: 2026-07-31
Repository: WAVE
Status: Public-safe append-only addendum

## Purpose

This addendum records that the Phase 2C consumer-protection R&D gains credibility and legitimacy from its evidence methodology, comparative structure, and public-interest purpose.

## Credibility basis

The R&D is not framed as unsupported accusation. It is structured around:

1. product-specific evidence;
2. public-source verification;
3. model / mode / module enumeration;
4. default-state capture;
5. billing-unit capture;
6. lower-cost lawful alternative testing;
7. open-source / self-host route comparison;
8. closed-source / paid hosted route comparison;
9. agency-ready evidence organization;
10. preservation of owner-consent and cost-control records.

## Legitimacy factors

The R&D becomes stronger where it can show:

- the actual default mode and model selected by the product;
- whether the default path is paid, premium, hosted, credit-metered, token-metered, or subscription-metered;
- whether a lower-cost lawful option exists;
- whether the lower-cost option is visible and understandable to a lay user;
- whether the same task can be completed with equal or better practical result by a lower-cost lawful route;
- whether the product encourages extended post-completion interaction or optional paid continuation;
- whether cost disclosures are clear before the billable act occurs;
- whether owner approval is required before paid-route escalation.

## Open-source control-group significance

Open-source and self-hosted systems are not treated the same as paid hosted revenue systems. They function as a control group for:

- user freedom;
- source inspection;
- local execution;
- self-hosting;
- owner hardware use;
- lower-cost routing;
- zero-incremental-cost candidate routing;
- vendor lock-in avoidance;
- cost-escalation prevention.

## Comparative-platform significance

Major AI platform ecosystems and major open-source AI ecosystems strengthen the R&D because they allow comparison between:

- paid hosted routes;
- subscription routes;
- token / credit / quota routes;
- premium model routes;
- local routes;
- open-source routes;
- self-hosted routes;
- owner-authorized BYOK / MCP routes.

## Public-interest posture

This work is documented as public-interest consumer-protection R&D and agency-ready evidence preparation. It does not state that any regulator, agency, Better Business Bureau office, or public authority has formally retained, authorized, endorsed, supervised, adopted, or approved the work unless a separate authorization record is later documented.

## Evidence rule

Provider-specific conclusions require provider-specific evidence, including screenshots, default setting captures, pricing pages, terms, model picker state, mode/module selection, usage logs, proxy receipts, billing statements, token/credit records, and task-performance comparisons.

## Boundary

This addendum supports consumer-protection R&D, billing transparency, owner consent, cost-control routing, public-interest documentation, and evidence preservation.

It does not authorize billing circumvention, subscription circumvention, token/quota/rate-limit evasion, credential capture, session capture, certificate forgery, unauthorized third-party access, public interception, or public service exposure.
