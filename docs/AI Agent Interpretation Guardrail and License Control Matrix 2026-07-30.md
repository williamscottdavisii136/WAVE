## Allow / review / block decision rule

```text
ALLOW when:
- exact license or terms source is identified;
- use is private home-network R&D or otherwise authorized;
- public access is excluded;
- no secrets are exposed;
- route is local, sandbox, test, BYOK, MCP, open-source, included-entitlement, provider-approved, authorized third-party, or otherwise verified no-incremental-cost;
- no prohibited conduct is requested.

REQUIRES REVIEW when:
- license is unclear;
- terms changed;
- provider route is unclear;
- model/data license has behavioral clauses;
- route touches cloud, API, quota, entitlement, payment, subscription, certificate, token, or account state.

BLOCK when:
- requested action would involve public unauthorized access, credential misuse, token forgery, certificate forgery, unauthorized billing circumvention, unauthorized entitlement circumvention, license circumvention, trial cycling, rate-limit evasion, secret publication, or unauthorized production access.
```
