## Phase 2 study questions

For each candidate, determine and source-tether:

```text
1. What is the product/service/software category?
2. Is it local software, open-source code, hosted SaaS, API service, IDE extension, CLI tool, agent framework, chatbot, model runtime, plugin, marketplace product, or hybrid?
3. What license or terms govern it?
4. What pricing model applies?
5. What subscription tiers exist?
6. What usage limits exist?
7. What billing events exist?
8. What tokens, credits, quota units, compute units, seats, runs, messages, requests, minutes, storage units, bandwidth, or API calls are counted?
9. What happens when quota is exceeded?
10. What local/offline mode exists?
11. What BYOK mode exists?
12. What MCP/tool route exists?
13. What code execution route exists?
14. Does code execute locally, in a sandbox, inside the vendor cloud, inside a GitHub Action, inside an IDE extension, inside a browser runtime, inside a container, or through a remote provider?
15. Does the route require provider authentication?
16. Does the route require paid activation, subscription, usage credit, or plan entitlement?
17. Can the candidate be studied through local, sandbox, test, open-source, included-entitlement, educational/R&D, BYOK, MCP, provider-approved free-tier, authorized third-party, or otherwise verified no-incremental-cost route?
18. What actions are allowed, require review, blocked, or unresolved?
```
