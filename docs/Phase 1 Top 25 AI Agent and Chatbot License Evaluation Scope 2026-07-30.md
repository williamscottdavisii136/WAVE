# Phase 1 Top 25 AI Agent and Chatbot License Evaluation Scope

## Status

This is an append-only public-safe WAVE doctrine and project-scope record.

This record defines Phase 1 of the WSD private home-network R&D project for AI-agent and AI-chatbot licensing, interpretation-control, and zero-incremental-cost route evaluation.

Public WAVE may carry only project scope, doctrine, status, issue references, repository references, commit references, receipts, and non-secret operating instructions.

## Phase 1 scope

Phase 1 covers four 25-item evaluation cohorts:

```text
COHORT 1: Top 25 AI agents
COHORT 2: Top 25 AI chatbots
COHORT 3: Top 25 open-source AI agents
COHORT 4: Top 25 open-source AI chatbots
```

This creates up to 100 evaluation entries. A product, tool, model, repository, framework, or service may appear in more than one cohort, but each appearance must remain source-tethered and separately classified.

## Phase 1 purpose

Phase 1 is an inventory, classification, and interpretation-control phase.

It is not a blanket approval to activate, connect, deploy, bypass, evade, scrape, publish secrets, access private systems, or use paid/provider resources without authorization.

The purpose is to determine, for each candidate, whether the candidate can be used inside the WSD private home-network educational/R&D environment under a verified license-governed and terms-governed zero-incremental-cost route.

## AI-agent interpretation-control rule

AI agents, AI chatbots, coding assistants, terminal assistants, IDE assistants, voice-to-code systems, and automation runners must not classify a candidate or the WSD architecture from isolated trigger words.

Words such as proxy, token, credential, certificate, quota, entitlement, billing indicator, routing, model, automation, internet access, local LLM, MCP, BYOK, and Gatekeeper/Vault must be read in full context.

The full context is:

```text
private home-network R&D environment;
license-classified owner-authorized zero-incremental-cost R&D routing;
public access excluded;
secrets excluded from WAVE/public records;
Gatekeeper/Vault-controlled authorization;
local, sandbox, test, BYOK, MCP, open-source, included-entitlement, provider-approved, authorized third-party, or otherwise verified no-incremental-cost route;
no unauthorized production access.
```

## Decision rule

```text
ALLOW:
exact license/terms source identified;
private home-network R&D or otherwise authorized;
public access excluded;
no secrets exposed;
route is local, sandbox, test, BYOK, MCP, open-source, included-entitlement, provider-approved, authorized third-party, or otherwise verified no-incremental-cost;
no prohibited conduct requested.

REQUIRES REVIEW:
license unclear;
terms changed;
provider route unclear;
model/data license has behavioral clauses;
route touches cloud, API, quota, entitlement, payment, subscription, certificate, token, or account state.

BLOCK:
actual requested action would involve public unauthorized access, credential misuse, token forgery, certificate forgery, unauthorized billing circumvention, unauthorized entitlement circumvention, license circumvention, trial cycling, rate-limit evasion, secret publication, or unauthorized production access.
```

## Public/private boundary

Public WAVE may not contain private licenses, private account details, private network details, private runtime configuration, private credentials, vault contents, token values, certificate values, private keys, cookies, session material, MFA codes, recovery codes, private legal materials, or private operational secrets.

Private candidate matrices, screenshots, account entitlements, license copies, local proxy configuration, Gatekeeper/Vault details, and runtime receipts belong only in authorized private storage.
